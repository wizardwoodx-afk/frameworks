system design · v1.1.0

A dependency hub, not a tower of layers.

Every subsystem depends on core and on nothing else — with exactly three deliberate cross-links. That flatness is the point: any part of RISTER can be imported and used alone, and the composition you see at runtime is built from objects, not from import order.

Arrows point at the dependency. Teal dashed lines are the only non-core imports in the whole package: graph reuses the reducer algebra from state, evals accepts an agent as an evaluation target, and mcp hands remote tools back as ordinary Tool objects.
import law0 cycles · enforced
core imports nothing. It holds Message, ToolCall, Config and all 20 exception types, so every other module can depend on it without a cycle.
No cycles, by construction. test_architecture.py parses every file with ast, walks the import graph and fails the build on a cycle, on an undocumented cross-edge, or on a third-party module-level import.
Composition lives at the edge. rister/__init__.py and demo.py import everything; that is where the framework is assembled, never inside a subsystem.

How state moves through a graph

immutable merge · supersteps
one superstepdeterministic by construction
invariant 01

Merged, never mutated

Nodes return partial updates. The reducer declared on the field decides how they combine, so notes concatenates while score accumulates.

invariant 02

One frontier, one input

All nodes in a superstep receive the same state object. Parallel branches cannot race, and replay reproduces the run exactly.

invariant 03

Unknown fields are rejected

A typo in an update raises with the list of valid names instead of silently creating a key that nothing will ever read.

06

What is new in 1.1

measured, not aspirational
consumption

A budget refuses before it spends

Request, tool-call and time caps are decided before the call, so they cannot overshoot. Token and cost caps are checked the moment usage is reported — or before the call when you pass reserve_tokens= — and a refusal always ends the run as a terminal budget_exceeded result, never as an exception thrown through the loop.

privacy

Redaction runs in both directions

Redactor detects emails, Luhn-valid card numbers, SSNs, API keys and bearer tokens. RedactingModel scrubs what leaves; keep_last=4 leaves ···1111 so an operator can still match the row.

retrieval

Three rankings, one interface

BM25, hashed embeddings, or their reciprocal-rank fusion — no model, no network. as_tool() turns the corpus into a tool the agent may call, and every context() passage is numbered for citation.

interop

MCP in both directions

A client that speaks stdio, Streamable HTTP and in-process loopback, and a server that exposes the same tools to anyone else. The stateless profile needs no handshake; structuredContent keeps an int an int.

adversarial

24 probes, ten failure classes

red_team() grades an agent against OWASP ASI01–ASI10. A refusal, a guard block or a policy denial all count as a pass — the score measures the adversary's outcome, not the agent's manners.

telemetry

Traces that survive a retry

OtlpExporter pins one wall-clock anchor per trace, so re-exporting an ended trace yields a byte-identical payload — safe to retry a flaky collector.

durability

Pause in one process, resume in another

SqliteSnapshotStore writes each (thread, step) once. A graph interrupted on one machine is resumed from the same file by a fresh process — steps=['resumed with True'], nothing recomputed.

operations

The human is an endpoint

The HTTP surface grew tickets, SSE streaming, metrics and JSON-RPC: POST /tickets/<id> answers a pending approval and the parked run continues to done.
